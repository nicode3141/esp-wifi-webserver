# ESP-IDF SoftAP Webserver

ESP-IDF project to serve static websites from flash over HTTP.
WiFi credentials are stored in NVS.
Based on the Espressif tutorials _Basic HTTP server/SoftAP_.

### Features

- Secure SoftAP
- Credentials loaded from NVS (encryption possible)
- Static file server
- Allows assets and a dev-ready frontend folder

Tested on the ESP32-S3 board
